🔧 二次开发指南

    

      
📄 源码结构

        
server.js：HTTP 服务 / JSON API / 报告历史 / 批量导出 / 定时任务 / CLI 模式（约 600 行，中文注释）

           engine.js：抓榜与解析 / 元数据与 README / 英译中 / 七问分析 / 报告生成（与桌面版 app.py 同一套逻辑）

      
🗂 不改代码即可扩展

        
data/kb_projects.json 项目知识库 ｜ data/dict_terms.json 中英词典 ｜ data/categories.json 分类模板（关键词 + 七问文案） ｜ data/mirrors.json 镜像源清单（可增删加速站 / Firecrawl 配置）。改完刷新页面立即生效。

      
⌨️ 命令行模式

        
可接入 Windows 任务计划做定时报告（Web 版「⏰ 定时报告」已自动登记）：

           node server.js --cli --since monthly

           node server.js --cli --since 2026-08-01 --source official

           node server.js --cli --html-file data/trending_cache_daily.html

      
🌐 界面中英切换

        
界面文字集中在 UI_STR 双语表中，可增补更多语言；协议判定表 LICENSE_INFO 可增删协议规则；报告正文保持中文。
